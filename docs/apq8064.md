# APQ8064

Datasheet: <https://www.qualcomm.com/content/dam/qcomm-martech/dm-assets/documents/snapdragon_600_apq_8064_data_sheet.pdf>

Per the datasheet, the boot flow starts with the RPM (Resource Power Manager)
boot ROM (mask ROM), which is a subsystem with an Arm7 core.
The boot ROM sits at `0x0000_0000` and is 128KB in size.

## Boot Modes

Boot modes are documented in the datasheet in chapter 6, pages 40-42.

This here only summarizes the configuration bits.

### Fast Boot

NOTE: Not to confuse with Android's fastboot.

| `BOOT_CONFIG[5:0]` | `BOOT_CONFIG[6]` = `1` = fast boot |
| ------------------ | ---------------------------------- |
| `0b000000`         | SDC3 followed by HS-USB            |
| `0b000001`         | SDC3 followed by SDC1              |
| `0b000010`         | SDC3 followed by SDC2              |
| `0b000011`         | SDC1 (eMMC)                        |
| `0b000100`         | SDC2                               |



### Secure Boot

| `BOOT_CONFIG[5:0]` | `BOOT_CONFIG[6]` = `0` = secure boot               |
| ------------------ | -------------------------------------------------- |
| `0b000000`         | No secure boot, as `BOOT_CONFIG[4:0]` = `0`        |
| `0b000001`         | Secure boot1 from `OEM_SECURE_BOOT1` configuration |
| `0b000010`         | Secure boot2 from `OEM_SECURE_BOOT2` configuration |
| `0b000011`         | Secure boot3 from `OEM_SECURE_BOOT3` configuration |
| `0b000100`         | Secure boot4 from `OEM_SECURE_BOOT4` configuration |
